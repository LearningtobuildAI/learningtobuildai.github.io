PART 3Engineering & Build Guide

9Engineering Breakdown
  • Encoding layer — converts digital bits into DNA base sequences and adds redundancy. Key parts: binary-to-base mapping, error-correcting code, indexing primers for random access.
  • Writer — inserts the encoded DNA into a host genome. Key parts: CRISPR-Cas9 or Cas12, guide RNAs, donor DNA templates, CRISPR-associated transposases for larger payloads.
  • Host cell — the living chassis that stores and replicates the data. Key parts: dormant bacterial or yeast strain, genome with safe insertion sites, selection markers.
  • Archive — keeps cells alive but dormant for long periods. Key parts: cryopreservation or lyophilisation, temperature-controlled storage.
  • Reader — recovers and sequences the stored DNA. Key parts: cell revival and DNA extraction, PCR amplification, high-throughput or nanopore sequencer.
  • Decoder — reconstructs the original file from sequencing reads. Key parts: base-calling software, error correction, file reassembly.
10How It Would Be Made — Step by Step
  1. Encode the data. Split the digital file into blocks, add error-correcting code, map each block to a sequence of A, T, G and C, and attach primer sites so any block can be retrieved on its own.
  2. Design the writing strategy. Choose safe insertion sites in the host genome, then design guide RNAs and donor DNA templates that direct the CRISPR system to those sites.
  3. Prepare host cells. Grow a dormant cell line and make it competent to take up the CRISPR components and donor DNA.
  4. Write the data. Introduce the CRISPR machinery and donor DNA. The system inserts data blocks into the genome. Repeated rounds can add more blocks, but each round risks damaging the cell.
  5. Select and verify. Use antibiotic or fluorescent markers to find cells that took up the data, then sequence the targeted regions to confirm the insertions are correct.
  6. Archive the cells. Freeze or dry the culture and store it under controlled conditions so the cells stay dormant and genetically stable.
  7. Retrieve the data. Revive the cells, extract their DNA, amplify the inserted regions with the primer sites, and read them with a DNA sequencer.
  8. Decode. Convert the sequencing reads back into bits, correct errors, and reassemble the original file.
11Prerequisite Technologies
  • EXISTS DNA synthesis — Needed to make the donor DNA and guide sequences; current synthesis is accurate for short pieces but costly and error-prone for long ones.
  • EXISTS CRISPR genome editing — The only practical way to write into a living genome, but payload size and the number of simultaneous edits are still limited.
  • EXISTS DNA sequencing — Reading the data back requires fast, cheap sequencing; current platforms are good but not yet at archive scale for living cells.
  • PARTIAL Error-correcting codes for DNA — DNA storage suffers insertions, deletions and substitutions, so robust codes are still being developed for in vivo use.
  • PARTIAL Long-term storage of living cells — Cells must stay dormant and genetically stable for decades; cryopreservation works but is energy-intensive and not proven over centuries.
  • NOT YET In vivo writing of large datasets — No one has written more than a few kilobytes into a living genome with high fidelity, and random access at scale is unproven.
12Theoretical Path to Reality
  1. Now: In vitro DNA data storage stores small files in synthetic DNA outside cells. — Proof that DNA is an extremely dense and durable medium for digital data.
  2. Next: In vivo recording of small data such as images or text into bacterial genomes using CRISPR. — Biological memory that replicates along with the cell, without external synthesis.
  3. Next: Scalable, high-fidelity writing of megabytes into living cells with reliable random access. — A practical archival medium for cold data that is rarely read.
  4. Longer term: Petabyte-scale biological archives that last centuries with minimal power. — A replacement for tape and disk in long-term, low-energy storage.
