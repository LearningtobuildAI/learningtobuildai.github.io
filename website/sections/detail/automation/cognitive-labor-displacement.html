4How It Works

These systems leverage recursive language model (LLM) chains that possess long-term memory and tool-use capabilities. They manage specialized sub-agents to perform various tasks autonomously, with minimal human oversight required for high-level strategic decision-making.

PART 3Engineering & Build Guide

9Engineering Breakdown
  • Base model — the language engine that understands the task and writes the plan. Key parts: transformer neural network, trained weights, tokenizer, instruction-tuned checkpoint.
  • Planning loop — turns a goal into steps, checks each result and revises when something fails. Key parts: task decomposer, reasoning scratchpad, critic or verifier, replanner.
  • Memory — keeps project state alive across days, not just one conversation. Key parts: working context window, embedding model plus vector index for retrieval, episodic log of past actions and outcomes, structured project state store.
  • Tool and action layer — lets the agent actually change things rather than only talk. Key parts: API and function calling, code execution sandbox, browser and document tools, scoped credentials and permissions.
  • Multi-agent orchestration — splits work among specialised sub-agents and merges their output. Key parts: supervisor or router, role and persona prompts, message bus, concurrency, token and cost limits.
  • Evaluation, guardrails and audit — catches failure before it reaches real work. Key parts: task benchmark suite, trajectory logging, output filters, human approval gates.
  • Serving infrastructure — runs many agents at once at tolerable latency and cost. Key parts: GPU accelerators, inference server with batching and key-value cache, queue and rate limits, monitoring.
10How It Would Be Made — Step by Step
  1. Collect and curate data. Web text, code, documentation and licensed material are filtered, deduplicated and decontaminated against test sets.
  2. Pre-train the base model. The network learns to predict the next token across trillions of words, which builds general language and reasoning ability.
  3. Align for instruction and tool use. Supervised fine-tuning, preference learning and records of correct tool calls teach the model to follow a goal and emit structured actions.
  4. Add retrieval memory. Documents and past project state are embedded into vectors and stored in an index the agent queries before each step.
  5. Build the agent loop. A controller alternates reason, act, observe: it calls tools, reads results, and decides the next step. Code runs in a sandbox with scoped credentials.
  6. Layer orchestration. A supervisor agent decomposes the project, spawns sub-agents with narrow roles, passes messages and merges and checks their outputs against budget limits.
  7. Build the evaluation harness. Long tasks with checkable outcomes are run repeatedly to measure success rate, cost, and where the agent goes off track.
  8. Deploy behind guardrails. Agents go live with permission scopes, spending caps, full action logs and human approval at defined decision points.
  9. Close the loop. Failure traces are mined and fed back into fine-tuning, prompt and tool design, and new evaluations.
11Prerequisite Technologies
  • EXISTS Large pre-trained transformer models — they supply the general language and reasoning ability the whole system rests on.
  • PARTIAL Reliable tool use and error recovery — models call functions well in short bursts but degrade over long chains of steps and rarely recover cleanly from mistakes.
  • PARTIAL Long-horizon task evaluation — without tests that run for hours or days, improvement in real project execution cannot be measured honestly.
  • PARTIAL Secure sandboxing, identity and permissions — an agent with real credentials and write access is a security and liability problem that current tooling only partly contains.
  • NOT YET Project-scale persistent memory — no deployed system yet maintains coherent, auditable state across months of work by many agents.
12Path to Full Scale
  1. Now: assistants that complete short, bounded tasks with a human in the loop — time savings on drafting, search, coding and data handling.
  2. Next: agents with persistent memory and real tools running multi-step workflows under review — whole processes, not single tasks, handed over with a reviewer checking outputs.
  3. Next: supervisor agents coordinating sub-agents across a live project, with humans approving budget and key decisions — small teams overseeing work of a size that used to need many more people.
  4. Longer term: auditable end-to-end delivery of defined knowledge-work processes — genuine substitution of certain roles — but full executive project management without oversight remains a research and governance frontier, not a demonstrated capability.

18Glossary
Recursive LLM chains
Series of language models that can call upon each other and share context, enabling complex reasoning and problem-solving capabilities.
Long-term memory
Capacity for an AI system to retain information over extended periods, allowing it to learn from past experiences and apply this knowledge in new situations.
Tool-use capabilities
The ability of AI agents to interact with external tools or systems to perform specific tasks, such as data analysis or project management software.
