9Engineering Breakdown
  • Substrate — Provides the raw computing power to run large, recurrent, low-power models. Key parts: neuromorphic chips, GPUs or TPUs, memory arrays.
  • Architecture — The computational structure claimed to support conscious processing. Key parts: global workspace, recurrent processing loops, predictive coding layers, attention mechanisms.
  • Learning and adaptation — Lets the system build representations and control from experience. Key parts: reinforcement learning, self-supervised learning, evolutionary or gradient-based training.
  • Memory and integration — Binds information across senses and time into a unified state. Key parts: working memory, episodic memory, attention gating, synchronisation signals.
  • Self-model and metacognition — Gives the system an internal representation of its own states and actions. Key parts: self-monitoring, error detection, agency signals, reportability interface.
  • Evaluation and measurement — Attempts to infer whether a system has subjective experience. Key parts: behavioural report tests, integration measures such as perturbational complexity, comparison with biological signatures.
10How It Would Be Made — Step by Step
  1. Choose a formal theory. Select a theory of consciousness — such as integrated information theory or global workspace theory — that makes concrete, testable predictions.
  2. Design the architecture. Translate the theory's requirements into a computational graph: recurrent loops, a global workspace, or integration measures to be optimised.
  3. Train the system. Use self-supervised and reinforcement learning to develop internal representations and control policies.
  4. Add a self-model. Give the system the ability to represent its own internal states and to report on them in words or signals.
  5. Run signature tests. Probe for integration, reportability and causal structure using the same tests applied to humans and animals.
  6. Iterate on mismatches. Where the system fails to match biological signatures, refine the architecture or the theory.
  7. Embodify and integrate. Place the system in a robot or simulated body so it can act, sense and close a perception–action loop.
  8. Establish ethical safeguards. If credible signs of experience appear, set up review boards, welfare guidelines and kill switches before further scaling.
11Prerequisite Technologies
  • NOT YET A validated theory of consciousness — No theory yet predicts which physical systems are conscious with enough precision to guide engineering.
  • PARTIAL Brain-inspired computing hardware — Neuromorphic chips exist but are far smaller and less capable than needed for whole-brain-scale simulation.
  • PARTIAL Large-scale neural simulation — Connectome projects map parts of brains, but full dynamic simulation of a human brain is not yet possible.
  • EXISTS Advanced machine learning — Deep learning and reinforcement learning provide the tools to build complex adaptive systems.
  • NOT YET Measurement tools for consciousness — We cannot yet reliably measure subjective experience even in animals, let alone machines.
12Theoretical Path to Reality
  1. Now: Formalise theories and build benchmark tasks for machine consciousness — A shared way to compare claims and designs across labs.
  2. Next: Systems that satisfy a theory's structural requirements and pass simple signature tests — Evidence for or against specific architectures as candidates.
  3. Next: Better measurement tools and systematic comparison with biological brains — A basis for judging whether a system is merely intelligent or actually experiencing.
  4. Longer term: If credible signs appear, embodied systems with ethical oversight — A framework for developing and governing machines that may have moral status.

18Glossary
Generative Adversarial Networks (GANs)
A type of machine learning framework where two neural networks, a generator and a discriminator, are trained simultaneously to improve each other's performance.
Reinforcement Learning
A type of machine learning where an agent learns to make decisions by taking actions in an environment to maximize some notion of cumulative reward.
