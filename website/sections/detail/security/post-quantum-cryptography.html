PART 1Executive Overview
1Definition

Post-Quantum Cryptography (PQC) refers to cryptographic techniques designed to be secure against both classical and quantum computer attacks. These methods are intended to replace existing public-key cryptography systems that could potentially be broken by a sufficiently powerful quantum computer.

2Problem It Solves

The primary problem solved by PQC is ensuring long-term security of cryptographic systems in an era when large-scale quantum computers may become available. Traditional public-key cryptography algorithms like RSA and ECC could be broken using Shor's algorithm on a sufficiently powerful quantum computer, making them vulnerable to attacks.

4How It Works

PQC schemes, particularly lattice-based ones, rely on the computational difficulty of certain mathematical problems that are believed to be hard for both classical and quantum computers to solve efficiently. Lattice-based schemes involve constructing high-dimensional lattices where finding short vectors is computationally challenging, which forms the basis for secure encryption and key exchange protocols.

Manufacturing for PQC involves developing and implementing new cryptographic standards and protocols that can be integrated into existing security frameworks without disrupting current systems. This includes testing and validating new algorithms through rigorous analysis and benchmarking.

9Engineering Breakdown
  • Mathematical foundations — provide hard problems that are believed to resist attacks by both classical and quantum computers. Key parts: lattice problems (e.g., Learning With Errors), coding theory problems, hash-based structures, multivariate polynomial systems.
  • Algorithm families — the actual cryptographic primitives used for key exchange and digital signatures. Key parts: key encapsulation mechanisms such as ML-KEM (CRYSTALS-Kyber), lattice-based signatures such as ML-DSA (CRYSTALS-Dilithium), hash-based signatures such as SLH-DSA (SPHINCS+), optional hybrid schemes combining classical and post-quantum algorithms.
  • Implementation libraries — run the algorithms efficiently and safely on real hardware. Key parts: constant-time software code, optimised arithmetic for large polynomials and matrices, hardware accelerators for embedded and server use, cryptographically secure random number generators.
  • Protocol integration — embed post-quantum primitives into the protocols that carry everyday traffic. Key parts: TLS 1.3 handshakes, SSH and IPsec, X.509 certificates and certificate authorities, messaging and VPN protocols.
  • Crypto agility and migration tools — let systems switch algorithms without redesign, and help organisations find what needs changing. Key parts: algorithm identifiers and negotiation, hybrid key exchange modes, cryptographic inventory and discovery tools, key management and rotation systems.
  • Security analysis and validation — test the algorithms for weaknesses, side channels and parameter mistakes. Key parts: public cryptanalysis, formal verification and proofs, standardised test vectors, certification against profiles such as FIPS 140-3.
10How It Would Be Made — Step by Step
  1. Choose a hard problem. Researchers select a mathematical problem that is believed hard for quantum computers as well as classical ones — lattices, error-correcting codes, hash functions or multivariate equations.
  2. Design a primitive. A key encapsulation mechanism or signature scheme is built on that problem, with a security proof and careful parameter choices.
  3. Submit for public review. The design is published and attacked by the global research community; weaknesses lead to tweaks or rejection.
  4. Standardise the algorithm. Standards bodies such as NIST select winners after years of analysis. Recent standards include ML-KEM, ML-DSA and SLH-DSA.
  5. Write efficient, safe code. Implementations must be fast, use little memory, and run in constant time to avoid leaking secrets through timing or power use.
  6. Integrate into protocols. The algorithms are fitted into TLS, SSH, VPNs and certificate systems, often alongside classical cryptography in hybrid mode so security does not depend on the new scheme alone.
  7. Test and certify. Developers run standard test vectors, check for side channels, and seek certifications so the code can be trusted in regulated environments.
  8. Deploy and migrate. Browsers, servers, phones and embedded devices are updated; long-lived secrets and firmware signing keys are replaced first because they must stay safe for decades.
11Prerequisite Technologies
  • EXISTS Lattice-based cryptography — provides the leading key exchange and signature schemes, with strong security evidence and practical key sizes.
  • EXISTS Hash-based signatures — offer a conservative fallback whose security rests only on hash functions, though signatures are larger.
  • PARTIAL Efficient polynomial and matrix arithmetic — needed to make lattice schemes fast enough for high-volume servers and low-power devices.
  • PARTIAL Crypto agility in systems and protocols — without the ability to swap algorithms quickly, migration to post-quantum cryptography will be slow and error-prone.
  • PARTIAL Post-quantum hardware security modules and secure elements — many keys are stored in tamper-resistant chips that must support the new algorithms before they can be used in critical infrastructure.
12Path to Full Scale
  1. Now: NIST post-quantum standards published; early adoption in browsers, libraries and pilot deployments — a tested set of algorithms that vendors can start implementing.
  2. Next: hybrid deployment in TLS, VPNs and code signing, plus cryptographic inventories across organisations — protection against 'harvest now, decrypt later' attacks on today's traffic.
  3. Next: migration of long-lived secrets, root certificates and firmware signing keys to post-quantum algorithms — security for data and devices that must remain safe for decades.
  4. Longer term: full transition as quantum computers capable of breaking current cryptography approach — continued trust in digital communications and infrastructure; if weaknesses are found, crypto agility allows another switch.

18Glossary
Post-Quantum Cryptography (PQC)
A set of cryptographic techniques designed to be secure against both classical and quantum computer attacks.
Lattice-based schemes
Cryptographic methods that rely on the difficulty of solving problems related to high-dimensional lattices, making them resistant to quantum attacks.
Shor's algorithm
A quantum algorithm capable of efficiently factoring large integers and solving discrete logarithm problems, which could break traditional public-key cryptography systems.
