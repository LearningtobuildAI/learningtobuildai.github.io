PART 1Executive Overview
1Definition

Post-Quantum Cryptographic Standards are encryption methods designed to be secure against attacks by quantum computers, specifically those that could break current cryptographic systems using Shor's algorithm.

2Problem It Solves

Current public-key cryptographic systems are vulnerable to quantum attacks due to Shor's algorithm. Post-Quantum Cryptographic Standards address this vulnerability by offering algorithms that can withstand such attacks, ensuring long-term data protection and privacy.

4How It Works

These standards utilize advanced mathematical structures such as lattice-based and isogeny-based cryptography. Lattice-based cryptography relies on the hardness of certain problems in high-dimensional lattices, while isogeny-based cryptography leverages the security of elliptic curve isogenies to provide secure key exchange.

9Engineering Breakdown
  • Mathematical primitives — provide the hard problems that quantum computers cannot solve efficiently Key parts: lattice problems (LWE, SIS), hash functions, error-correcting codes.
  • Key encapsulation mechanism (KEM) — securely exchange symmetric keys over a public channel Key parts: ML-KEM (formerly CRYSTALS-Kyber), other lattice-based KEMs.
  • Digital signature schemes — authenticate messages and verify identity Key parts: ML-DSA (formerly CRYSTALS-Dilithium), SLH-DSA (formerly SPHINCS+), Falcon.
  • Implementation and key management — make the algorithms fast, secure, and usable in real systems Key parts: optimized software libraries, constant-time implementations, hardware security modules (HSMs), secure key storage.
  • Migration and inventory tooling — find and replace vulnerable cryptography across an organisation Key parts: cryptographic discovery tools, protocol upgrades (TLS, SSH, VPN), certificate management.
10How It's Made — Step by Step
  1. Identify hard problems. Cryptographers study lattice problems and other candidates that resist known quantum algorithms such as Shor's.
  2. Design algorithms. Researchers construct key encapsulation and signature schemes with security proofs and practical performance targets.
  3. Public competition and cryptanalysis. Algorithms are submitted to open standardisation processes where global experts try to break them.
  4. Select and standardise. The US National Institute of Standards and Technology (NIST) selected algorithms and published the first post-quantum standards in 2024.
  5. Implement in software. Libraries such as OpenSSL and BoringSSL add support; hardware vendors develop acceleration for larger keys.
  6. Integrate into protocols. TLS, SSH, VPNs, and messaging apps adopt hybrid modes that combine classical and post-quantum algorithms.
  7. Migrate systems. Organisations inventory their cryptography, replace vulnerable algorithms, and manage larger keys and certificates.
  8. Monitor and update. Cryptanalysis continues; if weaknesses are found, new algorithms and standards are developed and deployed.
11Prerequisite Technologies
  • EXISTS Lattice-based cryptography research — provides the mathematical hardness assumptions that underpin the leading standards.
  • EXISTS Open standardisation process — ensures algorithms are peer-reviewed, interoperable, and widely trusted.
  • PARTIAL Efficient software implementations — many libraries now support post-quantum algorithms, but performance and side-channel resistance need more work.
  • PARTIAL Hardware acceleration for post-quantum crypto — larger keys and signatures increase computational load, so dedicated hardware is being developed.
  • PARTIAL Public-key infrastructure (PKI) that handles larger keys — certificates and protocols must be updated to carry bigger post-quantum keys and signatures.
12Where It Goes Next
  1. Now: First post-quantum standards published and early implementations in browsers and libraries — the ability to test and deploy quantum-resistant algorithms in real systems.
  2. Next: Hybrid deployment in TLS, VPNs, and messaging; inventory tools mature — protection against store-now-decrypt-later attacks for data in transit.
  3. Next: Full migration of critical infrastructure such as finance, government, and energy — quantum-resistant critical systems that can withstand future quantum computers.
  4. Longer term: Post-quantum algorithms become the default; classical algorithms deprecated — seamless security in a post-quantum world without user intervention.
  5. Ongoing: Continuous cryptanalysis and periodic updates to standards — resilience against advances in both quantum computing and classical cryptanalysis.

18Glossary
Shor's algorithm
A quantum computing algorithm that can efficiently factor large integers, breaking many of the cryptographic systems currently in use.
Lattice-based cryptography
A type of post-quantum cryptography that relies on the hardness of lattice problems for security.
Isogeny-based cryptography
A form of post-quantum cryptography that uses isogenies between elliptic curves to provide secure key exchange and encryption schemes.
