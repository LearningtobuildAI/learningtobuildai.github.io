9Engineering Breakdown
  • NPU core — performs the matrix and tensor arithmetic that dominates neural-network inference. Key parts: MAC arrays for low-precision math (INT8, INT4), dedicated on-chip SRAM, activation and normalization units.
  • Host CPU and GPU — run the operating system, orchestrate tasks and handle any model layers the NPU cannot. Key parts: CPU cores, integrated GPU, shared cache and interconnect.
  • Memory subsystem — feeds the accelerators with model weights and activations fast enough to keep them busy. Key parts: unified or shared LPDDR memory, memory controller, high-bandwidth fabric.
  • Software stack — turns trained models into instructions the NPU understands. Key parts: driver and runtime, graph compiler and quantizer, frameworks and APIs (e.g. ONNX, DirectML, Core ML).
  • Thermal and power management — keeps the chip within its power and temperature budget in a thin laptop. Key parts: voltage regulators, heat pipes and fans, dynamic frequency and power gating.
  • Model storage and loading — stores compressed models and loads them securely on demand. Key parts: NVMe solid-state drive, encryption and secure boot, model cache in memory.
10How It's Made — Step by Step
  1. Design the SoC. Architects define the NPU block, its instruction set and its connection to CPU, GPU and memory, then write and verify the register-transfer-level design.
  2. Fabricate the silicon. The design is taped out to a foundry and built on an advanced process node, where billions of transistors are patterned layer by layer on a silicon wafer.
  3. Package and test the chip. The die is cut, bonded into a package with memory and power delivery, and tested for defects before shipment.
  4. Build the mainboard. The packaged SoC is soldered onto a printed circuit board alongside memory, storage, power regulators and connectors.
  5. Assemble the laptop. The board, battery, display, keyboard and cooling system are fitted into the chassis and tested for fit and function.
  6. Enable the software. Drivers, compilers and OS integrations are written so that mainstream AI frameworks can target the NPU; models are quantized to low precision to fit.
  7. Validate performance and power. Engineers run inference benchmarks, measure battery life and thermal behaviour, and verify that AI features work reliably across applications.
  8. Flash, certify and ship. Final firmware and operating system images are installed, the device is certified for sale, and it is packed for distribution.
11Prerequisite Technologies
  • EXISTS Advanced semiconductor manufacturing — NPUs only make sense when millions of arithmetic units can be built cheaply on a small, low-power die.
  • EXISTS Low-precision arithmetic hardware — neural networks tolerate 8-bit and 4-bit math, which is far more energy-efficient than floating point.
  • EXISTS Model compression and quantization — large models must be shrunk to fit in laptop memory and run within a battery budget.
  • EXISTS Efficient inference runtimes — compilers and runtimes map model graphs onto NPU hardware without hand-tuning each model.
  • EXISTS High-bandwidth, low-power memory — inference is often memory-bound, so feeding the NPU is as important as the math itself.
12Where It Goes Next
  1. Now: NPUs of tens of TOPS in mainstream laptops, used for background blur, transcription and photo editing — always-on AI features that run locally without sending data to the cloud.
  2. Next: NPUs approaching 100 TOPS and unified memory architectures — running small and medium language models entirely on the device.
  3. Next: co-processing between NPU, GPU and CPU for mixed workloads — faster, more flexible local assistants that combine vision, speech and text.
  4. Longer term: on-device personal agents with persistent memory and privacy — AI that learns from your data without it ever leaving the laptop.
