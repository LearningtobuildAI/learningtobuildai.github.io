1Definition

The Harrow-Hassidim-Lloyd algorithm solves sparse linear systems with exponential scaling advantage in the matrix dimension, the primitive behind many proposed quantum machine-learning and optimisation speedups.

4How It Works

Quantum phase estimation writes the matrix eigenvalues into an ancilla register; a controlled rotation inverts each eigenvalue and the register is uncomputed, leaving the solution vector encoded in the amplitudes of the system qubits.

9Engineering Breakdown
  • Input encoding — turns the classical vector b and matrix A into quantum states. Key parts: amplitude-encoding routine, sparse matrix oracle, quantum RAM (proposed).
  • Hamiltonian simulation — implements the time evolution e^(−iAt) that phase estimation relies on, using a sparse-matrix decomposition (e.g. Lie–Trotter or qubitisation). Key parts: Trotter/LCU circuits, ancilla registers.
  • Phase estimation — writes the eigenvalues of A into a register with enough bits to resolve them. Key parts: Hadamard layer, inverse quantum Fourier transform.
  • Reciprocal rotation — rotates an ancilla qubit by an angle proportional to 1/λ, inverting each eigenvalue. Key parts: controlled-Ry rotations, angle lookup.
  • Uncompute and postselect — undoes phase estimation and keeps only runs where the ancilla was measured in the right state. Key parts: inverse phase estimation, ancilla measurement.
  • Readout — extracts useful information from the solution state, usually by sampling observables rather than reading amplitudes. Key parts: Hadamard/test circuits, repeated measurements.
10How It Would Be Made — Step by Step
  1. Map the problem. Write A as a sparse Hermitian matrix and b as a normalised vector, and check the condition number κ — runtime grows roughly linearly with κ.
  2. Prepare b. Load the vector's amplitudes into the system register, a step whose cost can wipe out the speedup unless b has special structure.
  3. Evolve under A. Run Hamiltonian simulation to apply e^(−iAt) for the time needed to resolve eigenvalues.
  4. Estimate eigenvalues. Phase estimation writes each λ into an ancilla register as a binary fraction; the register needs about log(κ/ε) bits.
  5. Invert and rotate. A controlled rotation maps λ to an ancilla amplitude of roughly C/λ, inverting small eigenvalues most strongly.
  6. Uncompute. Reverse phase estimation so the eigenvalue register returns to its initial state and the solution stays in the system register.
  7. Postselect. Measure the ancilla; keep only the successful outcomes, which occur with probability around 1/κ², and repeat until enough samples accumulate.
  8. Read out. Use the state as input to further quantum routines, or measure chosen observables many times to estimate output properties.
11Prerequisite Technologies
  • NOT YET Fault-tolerant quantum computer with thousands of logical qubits — HHL needs deep circuits and error correction; today's noisy machines cannot run it at useful size.
  • PARTIAL Efficient Hamiltonian simulation — algorithms exist and small instances have run, but cost at practical matrix sizes is not demonstrated.
  • NOT YET Efficient state preparation and qRAM — loading arbitrary classical data can cost more than the classical solve it replaces.
  • PARTIAL Quantum readout of the solution — amplitudes cannot be read directly; only sampled properties are accessible, which limits which problems benefit.
  • EXISTS Well-conditioned sparse problems — the algorithm's advantage requires sparse, low-condition-number matrices and the right output model.
12Theoretical Path to Reality
  1. Now: proof-of-principle runs on a handful of qubits solving tiny 2×2 or 4×4 systems — confidence that the circuit blocks work, but no practical speedup.
  2. Next: early fault-tolerant versions that avoid full phase estimation and use error mitigation — larger systems and cheaper circuits, still short of a proven advantage.
  3. Next: resource estimates for real problems (fluids, materials, machine learning) identifying where an advantage survives end-to-end costs — a clear list of target applications worth chasing.
  4. Longer term: fault-tolerant demonstration on a problem where the whole pipeline beats the best classical solver on time or energy — a genuine quantum linear-solver tool, and a template for other algorithms.
