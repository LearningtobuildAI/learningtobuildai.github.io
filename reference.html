Photo Generating (Rule Book)

PHOTO UNIQUENESS ENFORCEMENT MODULE (MASTER EDITION): every photo on the site must be unique, context-correct, and used only once, except in the Live World Intelligence Feed or domain slot pages.

  1. Global Image Registry (Enforce_photo_uniqueness): track image_id, image_hash, domain, section, card, timeline, source_prompt, timestamp, and allowed_reuse.
  2. Hashing Engine: compute perceptual hash, average hash, and difference hash for every generated photo to detect duplicates, near-duplicates, and modified duplicates.
  3. Uniqueness Rules: allowed reuse only for Live World Intelligence Feed, domain-specific slot pages, and timeline continuity if explicitly marked. Reuse is forbidden across domains, sections, cards, timelines, matrix entries, and hero banners.
  4. Duplicate Detection Logic (Photo_context_checker): hash new image, compare against global registry, check allowed_reuse, approve if allowed, otherwise reject and regenerate.
  5. Regeneration Trigger (Upgrade_photo_prompt, Activate_photo_gen): when duplicate is detected, regenerate with upgraded prompt quality for detail, realism, domain specificity, material accuracy, and uniqueness constraints.
  6. Domain Slot Enforcement (Check_domain_root_page): each domain slot must maintain a unique photo, unique prompt, and unique metadata for hero, summary, cards, timeline, matrix, breakthroughs, companies, and future forecasts.
  7. Live World Intelligence Feed Exception: reuse only in feed slot and domain live tab. Reuse is not allowed in hero, cards, timelines, matrix, or other domains.
  8. Photo Replacement Logic (Auto_update_site): remove duplicate, regenerate, rerun scanner, rerun uniqueness check, insert new photo, update registry.
  9. Full Module Output Format: 
    {
  status: "approved",
  uniqueness: "unique",
  hash: "0xA3F9C2D1",
  allowed_reuse: false,
  action: "integrate"
}
    {
  status: "rejected",
  uniqueness: "duplicate",
  hash: "0xA3F9C2D1",
  allowed_reuse: false,
  action: "regenerate"
}
  10. Continuous Monitoring: run uniqueness checks on every new photo, every domain update, every auto-update cycle, and every scanner pass.

Mission statement: strict, domain-aware, context-sensitive uniqueness enforcement that prevents duplicate photo reuse and maintains visual integrity across the 24/7 intelligence platform.
